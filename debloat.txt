# Fire TV debloat list. Measured on a Fire TV Stick Lite (AFTSS), Fire OS 7.7.1.7 (PS7717/5741), Android 9 / API 28.
# Other Fire OS 7 sticks share most of these packages; check each batch with `tools/batch.py show <N>` first.
# Base: the cleanyourtv example lists toshiba-fire-tv-aftha004 (same build PS7717.5741N) and
# amazon-fire-tv-stick-4k-2018 (MIT, https://github.com/Gathin23/cleanyourtv), plus packages found on the device.
#
# WARNING: use at your own risk. Disable only (pm disable-user --user 0), never uninstall. Everything here can be
# re-enabled with tools/restore.sh. Apply one batch at a time and check the stick still works before the next.
#
# Apply one batch:  tools/batch.py apply <N>      (logs to backup/applied.log, then reboots + verifies)
# Undo:             tools/restore.sh              (re-enables everything in backup/applied.log)
#
# NOT listed, on purpose:
#   HOME / Settings / core: com.amazon.tv.launcher (also hosts android.settings.SETTINGS), com.amazon.firehomestarter,
#     com.amazon.tv.settings.*, com.amazon.device.settings, anything sharedUser=android.uid.system or PERSISTENT
#     (com.amazon.tifobserver, com.amazon.media.recommendations, com.amazon.neodelegate)
#   Prime Video / DRM: com.amazon.firebat, com.amazon.tv.support, all drm/widevine/playready HALs
#   Identity / SSO / profiles: com.amazon.imp, com.amazon.prism.android.service, com.amazon.aca, com.amazon.d3,
#     com.amazon.katoch, com.amazon.spiderpork, com.amazon.alta.h2clientservice, com.amazon.tv.turnstile
#   Appstore: com.amazon.venezia, com.amazon.tigris. OTA: com.amazon.device.software.ota*
#   Voice search on the remote: com.amazon.vizzini (+ aria, cardinal, alexa.datastore, alexadirectivebrokerservice)
#   Casting: com.amazon.cast.sink, dialservice, whisperlink/whisperplay, awvflingreceiver
#   Input / BT / keyboard / accessibility / TTS / screensaver / profile picker / captive portal (com.amazon.cpl)
#   Protected on this build (pm refuses without root), per cleanyourtv: com.amazon.device.metrics,
#     com.amazon.ftvads.deeplinking, com.amazon.client.metrics, com.amazon.device.logmanager,
#     com.amazon.device.crashmanager, com.amazon.diode, com.fireos.usagestats.proxy, com.amazon.tv.csapp, com.amazon.tv.oobe
